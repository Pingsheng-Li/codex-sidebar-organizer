# Sidebar Organizer：让越来越长的聊天列表重新有序

当你同时使用多台电脑、Codex 和 ChatGPT，项目与聊天会不断积累。本机任务、云端对话和不同项目挤在侧边栏里，找一段旧聊天越来越依赖滚动和搜索；手动整理一次之后，新增记录又会继续堆积。

Sidebar Organizer 就是为这个日常问题做的轻量开源插件。安装后，用一句自然语言指令，就能在支持原生侧边栏工具的 Codex 桌面会话中，按已核实的本机、远程主机、ChatGPT 云端和 Codex 云端来源，将项目与聊天收纳到可折叠分组。

我们的做法是“读取来源、生成方案、执行整理、回读核对”。插件复用客户端原生的分组、移动和排序能力，整理时保留置顶、项目归属、文件路径及已有手工分类。对于临时聊天标识、云端执行记录和内部保存格式不一致的情况，再用对应证据交叉核对；不能确认的条目保持原样，并明确报告。

它解决的不只是侧边栏太长，还包括多种来源混在一起难以区分、手动整理成本高，以及重复运行容易产生重复分组的问题。再次调用时会复用已有分组，只处理符合条件的未分类记录，让整理成为可以重复使用的日常操作。

项目以插件和独立 skill 两种形式提供，按需运行，无需额外服务器或 API Key。当前重点是 Codex 桌面端可读取范围内的可靠整理；更早历史的覆盖、自动折叠和跨设备同步会按实际能力说明。
